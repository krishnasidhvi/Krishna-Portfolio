- **Executive Hero & Dual Photo Switcher**: Features professional portrait (`/profile.jpg`) alongside a generated **3D AI Data Avatar** (`/avatar.png`) with 1-click view toggle.
- **Quantified Business Impact Cards**:
  - **99%+ Relational SQL Accuracy** (*Trida Labs - AgentSQL & MCP Guardrails*)
  - **-40% Data Anomaly Reduction** (*Global Payments - Automated Redshift Quality Frameworks*)
  - **+30% Pipeline Reliability & Scalability** (*Amazon - AWS Glue & Informatica*)
  - **-15% Fraud False Positives** (*Global Payments - Historical Anomaly Refinement*)
- **Interactive Technical Skills Matrix**: Categorized tech stack with real-time keyword search (*AgentSQL, MCP, Snowflake, Databricks, Redshift, AWS Glue, PySpark, Python, SQL, Tableau, Power BI*).
- **Interactive Agentic AI & ETL Pipeline Playground**: Browser simulator to view and execute:
  1. **AgentSQL & MCP Agent (Trida Labs)**: Schema-aware autonomous Text-to-SQL synthesis with deterministic join guardrails and RBAC verification.
  2. **AWS Redshift Anomaly Audit (Global Payments)**: Validates null percentage drift across payment channels.
  3. **AWS Glue PySpark Streaming Job (Amazon)**: Filters high-risk fraud payloads and writes deduplicated Parquet streams to Amazon S3.
- **Master's Degree Research Showcase**: Deep breakdown of UMBC research projects (*Real-Time License Plate Detection, Chicago Crime Analytics, Credit Card Fraud Prediction*) with interactive architecture popups.
- **Printable Master Resume Viewer**: Native 1-click **Print / Save as PDF** and **Copy Raw Text** modal.
